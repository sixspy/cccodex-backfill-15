## 审计凭证（backfill-15）

出证命运已定为**同步同事务**，全局只此一种：

- **重放即出证**：`BEGIN IMMEDIATE` 里同时改落库行与写 `audit_credentials`，同成同败；写证失败则落库一起回滚，账本另记一笔失败留痕。
- **一片一证**：`audit_credentials.slice_id` 唯一约束 + 写锁，两名对账员抢出证不会双写凭证行。
- **缺证即拒签**：已落库但没有凭证的片，出证闸口 409 拒签、绝不现场补证；唯一纠偏是对该片**整片重跑**，重跑与新凭证仍在同一事务里（凭证号带放次，如 `BF-01-20261110-00001-02`）。
- **台账**：计划 / 重放 / 重跑 / 闸口放行拒签 / 对账 / 目录再验逐笔留痕，失败留痕独立落库，不被主事务回滚吞掉。
- **覆盖目录**：只有「落库且持证」的片计入已齐；无证片单列缺口，`complete=false`，目录再验拒签。
- **页上拒签芯片**：窗口存在缺证片时页顶常亮，并标注片数与窗口。

四处并读：审计台账（`审计台账` 页签 / `/api/ledger`）、片键详情（`/api/slices/{id}`，含凭证与片内留痕）、出证闸口（`/api/slices/{id}/gate`）、覆盖目录（`/api/coverage-directory`）。

预留切口（未做）：整窗失败闭 vs 单片独立事务、与在线灌数互斥、重叠窗拒入、凭证外部时间戳锚定。
